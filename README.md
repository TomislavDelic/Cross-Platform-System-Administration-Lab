# Cross-Platform System Administration Lab

## About This Project

This repository documents my hands-on system administration labs across Windows, macOS, Linux, and cloud-based identity management platforms.

I have over three years of professional experience as a System Administrator, primarily working with Windows environments, Active Directory, Microsoft 365, endpoint administration, and end-user technical support.

I hold Microsoft Azure Administrator Associate (AZ-104) and Azure Fundamentals (AZ-900) certifications.

The goal of this project is to expand my existing skills into cross-platform system administration, identity and access management, and IT security through practical, realistic administration scenarios.

Each lab documents the environment, tasks performed, verification results, and technical issues encountered.

## Practical Lab Highlights

### Identity & Access Management

- Created and managed user accounts and security groups in Active Directory.
- Configured group-based NTFS and SMB permissions on Windows Server.
- Verified SMB access from a Windows 11 virtual machine using domain credentials.
- Configured JumpCloud users, group membership and push-based MFA.
- Managed Google Workspace accounts, organizational units and group membership.
- Enabled Google Workspace 2-Step Verification and tested authentication using an authenticator application.

### System Administration

- Practiced macOS local user and group administration.
- Used macOS Terminal commands to inspect user identities and permissions.
- Configured and tested Windows Server file sharing.
- Used virtual machines to simulate administration tasks across different operating systems.

### Troubleshooting & Verification

The labs emphasize verifying configuration changes rather than simply applying settings.

Examples include:

- Investigating domain user logon restrictions on a Windows domain controller.
- Testing Active Directory authentication and SMB file access from a separate client.
- Verifying effective access through security group membership.
- Testing MFA authentication after configuration changes.

Individual lab documentation includes relevant commands, verification results, screenshots where appropriate, and troubleshooting notes.

## Professional Experience and Lab Scope

My professional background includes Windows system administration, Active Directory, Microsoft 365, endpoint management, and technical support.

The macOS, JumpCloud, and Google Workspace projects represent dedicated hands-on lab experience rather than production administration experience.
